# Workflow

1. Clone repository
2. create your the new branch 
3. commit changes 
4. push changes to remote branch 
5. review changes in detail 
6. create pull request.
7. pull request aproval
8. delete old branch 
9. pull recent commit from pull request into local main
10. delete old branch in local

# Rules
