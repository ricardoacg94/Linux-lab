## Workflow

1. Clone repository
2. git status & git pull
3. create your the new branch 
4. commit changes 
5. push changes to remote branch 
6. review changes in detail 
7. create pull request.
8. pull request aproval
9. delete old branch 
10. pull recent commit from pull request into local main
11. delete old branch in local

## Rules

- No secrets in the repo
